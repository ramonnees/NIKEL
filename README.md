# NIKEL: Gerenciamento Financeiro Web

Aplicação web para controle financeiro pessoal, desenvolvida durante o curso
Codaí 2.0 (GrowDev).

🔗 **Demonstração:** https://ramonnees.github.io/NIKEL/

## Funcionalidades
- Registro de receitas e despesas
- Acompanhamento das movimentações
- Dados salvos no próprio navegador

## Tecnologias
HTML · CSS · JavaScript

## Como rodar localmente
1. Baixe ou clone o repositório
2. Abra o arquivo `index.html` no navegador

## Aprendizados
Primeiro projeto web completo: estrutura em HTML, estilização com CSS e
lógica em JavaScript, com manipulação de dados no navegador.
